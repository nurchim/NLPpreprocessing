# Pedoman Istilah Antarmuka

Media menggunakan bahasa Indonesia formal dan tetap memperkenalkan istilah teknis internasional saat diperlukan.

| Istilah teknis | Istilah antarmuka |
|---|---|
| text preprocessing | prapemrosesan teks |
| cleaning | pembersihan |
| case folding | penyeragaman huruf kecil |
| tokenization | tokenisasi |
| normalization | normalisasi |
| stopword removal | penghapusan kata henti |
| stemming | stemming (pengakaran kata) |
| noise | derau |
| pipeline | pipeline / rangkaian proses |
| versi pratinjau | versi pratinjau |
| named entity recognition | pengenalan entitas bernama (NER) |

## Prinsip UI/UX
- Satu layar = satu keputusan utama.
- Istilah teknis diberi keterangan singkat, bukan jargon tanpa konteks.
- Hasil akhir selalu disertai jejak proses.
- Peringatan muncul ketika preprocessing berpotensi membuang informasi semantik.
- Warna bukan satu-satunya penanda status; teks dan struktur tetap jelas.
- Tombol menggunakan kata kerja: **Proses Teks**, **Bandingkan Hasil**, **Atur Ulang**.
